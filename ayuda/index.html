Ayuda del modelador móvil

Guía rápida para usar el modelador en iPhone/iPad.

Volver al motor

Crear y seleccionar

  • Usa los botones de Caja, Esfera o Cilindro para crear primitivas.
  • Toca un objeto para seleccionarlo; se resaltará con un contorno turquesa.

Mover y ajustar

  • Arrastra el objeto seleccionado con el dedo para moverlo en el suelo.
  • Los botones Subir y Bajar ajustan la altura.
  • Rotar gira el objeto en pasos para alinear rápidamente.
  • Escala + y Escala - cambian el tamaño.

Eliminar

  • Selecciona el objeto y usa Eliminar para borrarlo.

Gestos de cámara

  • Pellizca para acercar o alejar.
  • Arrastra con dos dedos para orbitar la cámara.
